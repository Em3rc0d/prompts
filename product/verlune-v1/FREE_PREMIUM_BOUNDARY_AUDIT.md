## Development & Tech

Free:
- **Explain Code Clearly** — understand supplied code.

Premium:
- **Requirements Analysis** — transform a request into explicit implementation-ready requirements.
- **Evidence-first Code Review** — structured change review with evidence, severity, unknowns and ship-state semantics.

Material difference:
- Free explains an artifact.
- Premium supports higher-consequence engineering preparation/review with stronger contracts and decision semantics.
