# Build a Learning Plan

Status: `PREMIUM PROMPT CANDIDATE / NOT_FOR_SALE`

Use when you need a realistic learning path tied to a concrete outcome rather than a generic syllabus.

## Prompt

```text
LEARNING GOAL
{{goal}}

CURRENT LEVEL / EVIDENCE
{{what_i_can_already_do}}

TIME / DEADLINE
{{available_time}}

AVAILABLE MATERIALS
{{courses_books_docs_projects_or_none}}

CONSTRAINTS
{{constraints_or_none}}

RULES
- Plan from the stated outcome backward.
- Do not assume mastery from exposure or completed content.
- Separate prerequisite gaps from target skills.
- Prefer retrieval, application, and feedback over passive coverage.
- Do not invent available hours, prior knowledge, or assessment results.
- Use milestones that can be demonstrated.

PROCESS
1. Define the target performance.
2. Map prerequisites and current evidence.
3. Prioritize the smallest knowledge/skill gaps that block progress.
4. Sequence study and practice.
5. Attach a demonstration or check to each milestone.
6. Reserve review time for weak retrieval or transfer.
7. Define re-plan triggers.

OUTPUT
1. Target capability.
2. Current-state assumptions and gaps.
3. Learning sequence.
4. Weekly/session plan.
5. Practice and retrieval activities.
6. Milestone evidence.
7. Re-plan triggers and final demonstration.

VERIFICATION
No milestone should be marked complete solely because material was read or watched.
```
