# Static Prompt Quality Checklist

Use before calling a prompt `VALID`.

- [ ] Purpose is explicit.
- [ ] Required inputs are named.
- [ ] Important terms or variables are defined.
- [ ] Context boundaries are explicit.
- [ ] Constraints do not contradict each other.
- [ ] Process steps are actionable rather than decorative.
- [ ] Output format is specified where format matters.
- [ ] Unknown or missing information has a fallback behavior.
- [ ] Verification requirements do not claim unobserved runtime facts.
- [ ] The prompt does not rely on hidden Prompt Quarry repository paths.
- [ ] Third-party wording is not silently redistributed.
- [ ] Maturity/claim labels do not exceed available evidence.

Passing this checklist establishes static usability only. It does not establish behavioral superiority or certification.
